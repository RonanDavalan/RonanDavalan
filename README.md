## Ronan Davalan

Systems administrator and self-taught developer, independent. Debian and Linux infrastructure since 1997, supervision of AI models since 2023.

I build reliable, lasting solutions for small businesses and independents: automation scripts, sovereign local networks, command-line tools.

### What my tools do

**Voice and accessibility**

- [vosk-cli-dictation](https://github.com/RonanDavalan/vosk-cli-dictation): real-time dictation for Linux, offline, from the command line.
- [PiperRead](https://github.com/RonanDavalan/PiperRead): reads aloud any selected or copied text with a neural voice, no cloud service.
- [WhispSkrid](https://github.com/RonanDavalan/whispskrid): push-to-talk dictation for Linux: hold a key, speak, release; offline transcription typed at the cursor.

**Tools for language models**

- [mcp-server-diwall-browser](https://github.com/RonanDavalan/mcp-server-diwall-browser): an MCP server that gives a model the screenshot, the accessibility tree and the gestures of the browser where the operator is signed in, under their confirmation.
- [Diwall](https://github.com/RonanDavalan/diwall): lets a model see a web interface and replay browser scenarios.
- [Dinoer](https://github.com/RonanDavalan/dinoer): web research and structured extraction for language-model agents, with sourced reports.

**Windows**

- [WindowsOrchestrator](https://github.com/RonanDavalan/WindowsOrchestrator): PowerShell scripts for a reproducible configuration of dedicated Windows workstations.

### How the work is done

I design and direct; language models write the code under my supervision: Claude Code (Anthropic) on most projects, Google Gemini, Grok and Claude on WindowsOrchestrator. The credits of each project say who did what; for WindowsOrchestrator, they are in section 8.4 of its [developer guide](https://github.com/RonanDavalan/WindowsOrchestrator/blob/main/docs/en-US/DEVELOPER_GUIDE.md).
